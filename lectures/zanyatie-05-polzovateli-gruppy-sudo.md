## Содержание лекции

### Учётные записи

Учётная запись — имя, UID, основная группа, домашний каталог и оболочка. Ядро различает пользователей по номерам **UID** и **GID**; у root UID 0. В `/etc/passwd` одна строка на запись, семь полей через двоеточие. Служебные записи с UID меньше 1000 и оболочкой `nologin` нужны программам.

### Пароли

`/etc/passwd` читают все, поэтому хеши паролей хранятся в `/etc/shadow`, закрытом от обычных пользователей. Система хранит **хеш** пароля с **солью**: восстановить пароль по хешу нельзя, одинаковые пароли дают разные хеши. `passwd -S` выводит состояние пароля.

### Группы

Группа — набор учётных записей; права, выданные группе, получают все участники. Основная группа записана в `/etc/passwd`, дополнительные — в `/etc/group`. Права проверяются по первой подходящей тройке: владелец, группа, остальные.

### root и sudo

`sudo` выполняет команду от имени root, если в `/etc/sudoers` есть правило для пользователя или его группы. Пароль спрашивается у вызвавшего пользователя. `sudo -l` выводит действующие правила, править их нужно через `visudo`. Каждый вызов `sudo` записывается в журнал; команды внутри `sudo -i` — нет. **Принцип минимальных привилегий**: права root — только для отдельных команд и только когда они нужны.

### Создание пользователей и общий каталог

`groupadd` создаёт группу, `useradd -m -s /bin/bash` — учётную запись с домашним каталогом, `passwd` задаёт пароль. `usermod -aG группа имя` добавляет в группу; `usermod -G` без `-a` заменяет весь список групп. Общий каталог команды: `chgrp` на группу проекта и `chmod 2770`. Бит **setgid** на каталоге передаёт его группу новым файлам. Доступ проверяют от имени другого пользователя: `sudo -u имя команда`. `userdel -r` удаляет запись и домашний каталог.
