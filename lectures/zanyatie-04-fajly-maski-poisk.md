## Содержание лекции

### Каталоги и файлы

`mkdir -p` создаёт весь путь и не выдаёт ошибку, если каталог уже есть. `touch` создаёт пустой файл или обновляет время изменения существующего.

### Копирование, перемещение, удаление

`cp` копирует файлы, для каталога нужен ключ `-r`. `mv` переносит и переименовывает; внутри одной файловой системы данные не копируются. `cp` и `mv` заменяют существующий файл без вопроса: ключ `-i` спрашивает, `-n` пропускает. `rm` удаляет файлы без корзины, `rmdir` — только пустой каталог, `rm -r` — каталог с содержимым. Перед удалением содержимое выводят командой `ls` с тем же путём. Имя с пробелом берут в кавычки или ставят перед пробелом `\`.

### Маски

| Маска | Совпадает с |
|---|---|
| `*` | любыми символами |
| `?` | одним символом |
| `[abc]`, `[!abc]` | одним символом из набора или не из набора |
| `{a,b}` | каждым из вариантов |

Маску раскрывает оболочка до запуска команды; результат раскрытия показывает `echo`. Маска без совпадений и маска в кавычках передаются команде как есть. `*` не находит скрытые файлы. Перед `rm` маску проверяют командой `ls`.

### Поиск

`find каталог условия` обходит всё дерево: `-name` (маску берут в кавычки), `-type`, `-size` (округляет вверх), `-mtime` (полные сутки), `-exec` для каждого найденного файла, `-delete` — в конце и только после проверки списка. `2>/dev/null` отбрасывает сообщения об ошибках. `locate` ищет по базе и видит изменения после `updatedb`. `which` ищет программу в `PATH`, `type` сообщает, чем является имя.

### Справка

`man имя` открывает страницу справки: NAME, SYNOPSIS, DESCRIPTION. Внутри `/` ищет по тексту, `n` — следующее совпадение, `q` — выход. Разделы: 1 — команды, 5 — форматы файлов, 8 — администрирование (`man 5 passwd`). `man -f` показывает разделы страницы, `man -k` ищет по описаниям. `--help` — краткая справка программы, `help` — справка встроенной команды.
