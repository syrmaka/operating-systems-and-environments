## Содержание лекции

### Определение

Операционная система — комплекс программ, который управляет ресурсами компьютера и предоставляет их прикладным программам. Между прикладной программой и оборудованием лежат слои: программа → библиотеки → ядро ОС → оборудование.

### Системный вызов и режимы процессора

Процессор работает в двух режимах. В режиме ядра доступно всё оборудование, в пользовательском режиме — только своя память. Прикладная программа не обращается к диску или сети напрямую: она делает системный вызов, процессор переходит в режим ядра, ядро выполняет действие и возвращает результат. Прикладные программы, оболочка и графическая среда работают в пользовательском режиме, ядро — в привилегированном.

### История: проблема → решение → цена

История ОС разобрана по схеме «техническая проблема → решение → цена». Каждый этап объясняет, откуда взялась одна из функций современной ОС.

| Год | Этап | Что появилось |
|---|---|---|
| 1945 | работа без ОС | программа занимает машину целиком |
| 1956 | пакетная обработка (GM-NAA I/O для IBM 704) | резидентная система сама запускает следующую задачу, машина не простаивает между расчётами |
| 1964 | мультипрограммирование, IBM System/360 | несколько программ в памяти, защита памяти, привилегированный режим процессора |
| 1969 | UNIX, разделение времени | интерактивная работа с терминала, права на файлы, ядро на языке C переносится между машинами |
| 1981 | MS-DOS | персональный компьютер на одного пользователя |
| 1984 | графический интерфейс, Apple Macintosh | окна, значки, меню, мышь |
| 1991 | ядро Linux | открытая разработка |
| 2007+ | iOS и Android | мобильные системы |

Функции не исчезают: очередь заданий 1956 года и планировщик Ubuntu 24.04 решают одну задачу — порядок использования процессора — разными способами.

### Функции ОС

| Функция | Что делает ОС |
|---|---|
| управление процессами | запускает программы и делит между ними процессор (планировщик) |
| управление памятью | выделяет память процессам и разделяет её |
| файловая система | хранит данные в виде файлов и каталогов |
| управление устройствами | работает с оборудованием через драйверы |
| защита и права доступа | проверяет, кому что разрешено |
| интерфейс пользователя | командная строка (bash) и графическая среда (GNOME) |

На занятии работу планировщика показали на модели: одно ядро, три процесса, тридцать интервалов времени. Каждая смена процесса на ядре — переключение контекста.

### Классификация

ОС классифицируют по шести независимым признакам:

| Признак | Значения |
|---|---|
| число задач | однозадачная, многозадачная (кооперативная или вытесняющая) |
| число пользователей | однопользовательская, многопользовательская |
| назначение | настольная, серверная, мобильная, встраиваемая, реального времени |
| интерфейс | командный, графический, комбинированный |
| разрядность | 32 или 64 бита |
| лицензия | проприетарная, свободная |

Система реального времени гарантирует ответ в назначенный срок; важна гарантия, скорость сама по себе её не даёт. Отдельно разобрана архитектура ядра: монолитное (Linux), микроядро, гибридное (Windows NT, XNU в macOS). Ядро и дистрибутив различаются: Linux — ядро, Ubuntu — дистрибутив на его основе.
