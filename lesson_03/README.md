## Изученный материал

В ходе занятия были изучены следующие темы:

- Учётные записи пользователей.
- UID и GID.
- Файлы `/etc/passwd` и `/etc/shadow`.
- Хеширование и соль.
- Основная и дополнительные группы.
- Пользователь `root` и механизм `sudo`.
- Журнал `sudo`.
- Создание пользователей и групп.
- Общий каталог с флагом `setgid`.
- Проверка доступа от имени каждого пользователя.
